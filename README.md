# WebTrip · Il viaggio di una richiesta web
Sito statico (HTML, CSS, JavaScript) per spiegare DNS, HTTP, HTTPS/TLS e SMTP. Gruppo: Ali Moukafih, Raul Ungurean, Marco Degiovanni.
## Pubblicazione
Carica la cartella su GitHub, poi Settings > Pages > Deploy from a branch > main / root. I percorsi sono relativi.
## Prova in locale
`python -m http.server` nella cartella del progetto (serve per caricare i file JSON).
## Struttura
index.html, teoria/, laboratorio/, studio/, crediti.html, assets/, data/.
