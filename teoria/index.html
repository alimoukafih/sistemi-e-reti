Teoria

Otto obiettivi in sei sezioni. Ogni sezione rimanda all’attività corrispondente.

1 · Client e server

Il client (per esempio il tuo browser) fa una richiesta; il server la riceve e risponde. Come in un ristorante: tu ordini, la cucina prepara.

Per capirsi usano il modello TCP/IP: livello applicativo (HTTP, DNS, SMTP), trasporto (TCP, UDP), rete (IP) e collegamento (la rete locale, come Wi-Fi o Ethernet). Ogni livello si appoggia a quello sotto.

2 · Le parti di un URL

In https://www.esempio.it:443/guida/pagina.html?lingua=it#intro:

  • schema: https
  • host: www.esempio.it
  • porta: 443
  • percorso: /guida/pagina.html
  • query: lingua=it
  • frammento: intro (resta nel browser)

3 · HTTP: richieste e risposte

Una richiesta ha una riga iniziale (metodo, percorso, versione), le intestazioni e, a volte, un corpo. La risposta ha una riga di stato, intestazioni e corpo.

GET /index.html HTTP/1.1
Host: www.esempio.it

HTTP/1.1 200 OK
Content-Type: text/html

Metodi: GET legge, POST invia dati, PUT sostituisce, DELETE cancella, HEAD chiede solo le intestazioni.

Stati: 1xx informativi, 2xx successo, 3xx reindirizzamento, 4xx errore del client (404 non trovato, 401 non autenticato), 5xx errore del server.

4 · DNS

Il DNS associa un nome (www.esempio.it) a un indirizzo IP. Il browser controlla la cache; se non basta, chiede al resolver, che nella risoluzione ricorsiva fa tutto il lavoro: interroga il server radice, il server TLD (.it) e il server autorevole, poi restituisce l’IP. Nella risoluzione iterativa ogni server risponde indicando a chi chiedere dopo. La cache evita di ripetere il viaggio.

Provalo nel Laboratorio

5 · HTTPS e TLS

HTTPS è HTTP dentro un canale protetto da TLS. TLS offre cifratura (nessuno legge il contenuto), autenticazione del server tramite certificato e controllo dell’integrità (nessuno modifica i dati di nascosto).

Provalo nel Laboratorio

6 · SMTP

SMTP invia la posta tra client e server di posta con comandi testuali: EHLO, MAIL FROM, RCPT TO, DATA, QUIT. Il server risponde con codici: 250 (ok), 354 (inizia a scrivere il testo), 221 (chiusura), 550 (casella non esistente).
